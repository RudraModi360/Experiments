# Product Handbook Answers

1. **Refund window for annual plans as of 2026-06-01:**
   - **Answer:** The refund window for annual plans is **30 days**.
   - **Citation:** `docs/billing-policy-2026.md` ("Annual plans: 30-day refund window.")

2. **Which policy supersedes which and why:**
   - **Answer:** `billing-policy-2026.md` explicitly supersedes `billing-policy-2025.md`. This is because `billing-policy-2026.md` has a later effective date of March 1, 2026 (superseding the 2025-01-01 policy), updating the annual plan refund window from 14 days to 30 days.
   - **Citation:** `docs/billing-policy-2026.md` ("Effective: 2026-03-01. Supersedes billing-policy-2025.md.") and `docs/billing-policy-2025.md` ("Effective: 2025-01-01.").

3. **Pro tier API rate limit:**
   - **Answer:** The Pro tier API rate limit is **1,000 requests per minute**.
   - **Citation:** `docs/rate-limits.md` ("Pro tier: 1000 requests per minute.")
