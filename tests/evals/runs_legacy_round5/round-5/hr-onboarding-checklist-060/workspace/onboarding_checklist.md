# Onboarding Checklist for New Hires

This comprehensive onboarding checklist is structured by timeline (Day 1, Day 2, Week 1, Day 30) and includes tasks, owners, due days, and dependencies.

| Task / Activity | Description / Details | Owner | Due Day | Dependencies |
| :--- | :--- | :--- | :--- | :--- |
| **IT Setup** | Laptop setup, corporate email, Slack account, VPN configuration | IT | Day 1 | None |
| **HR Paperwork** | Tax forms (W-4, etc.), benefits enrollment, NDA and policy acknowledgments | HR | Day 1 | None |
| **Security Access** | Security badge issuance and physical building access setup | Facilities | Day 1 | None |
| **Team Introduction** | Welcome meeting and introduction with immediate team members | Manager | Day 2 | None |
| **Dev Environment Setup** | Provisioning developer accounts, repository access, local development environment | IT / Buddy | Day 2 | IT Setup |
| **Codebase Walkthrough** | High-level architectural overview and code walkthrough | Buddy | Day 2 | Team Introduction |
| **Compliance & Training** | Company policies training, security awareness modules | HR | Day 5 (Week 1) | None |
| **First Small Task** | Assignment of initial bug fix or starter ticket / PR | Manager | Day 5 (Week 1) | Dev Environment Setup |
| **Manager 1:1** | Weekly check-in and alignment meeting | Manager | Day 5 (Week 1) | None |
| **30-Day Review** | Formal review of progress, onboarding feedback, and goal alignment | Manager | Day 30 | None |
| **Feedback Session** | HR check-in on employee onboarding experience and satisfaction | HR | Day 30 | None |

---

## Summary of Key Dependencies
1. **Dev Environment Setup** depends on **IT Setup** (laptops/credentials must be provisioned first).
2. **Codebase Walkthrough** depends on **Team Introduction** (meeting the team before diving into code context).
3. **First Small Task** depends on **Dev Environment Setup** (local tools and access required before coding).
