# HR Onboarding Checklist (New Hire)
## Day 1
- IT setup: laptop, email, Slack, VPN (Owner: IT, Due: Day 1)
- HR paperwork: tax forms, benefits enrollment, NDA (Owner: HR, Due: Day 1)
- Security badge and building access (Owner: Facilities, Due: Day 1)
## Day 2
- Team introduction meeting (Owner: Manager, Due: Day 2)
- Dev environment setup (Owner: IT/Buddy, Due: Day 2)
- Codebase walkthrough (Owner: Buddy, Due: Day 2)
## Week 1
- Training: company policies, security awareness (Owner: HR, Due: Day 5)
- First small task assignment (Owner: Manager, Due: Day 5)
- 1:1 with manager (Owner: Manager, Due: Day 5)
## Day 30
- 30-day review (Owner: Manager, Due: Day 30)
- Feedback session (Owner: HR, Due: Day 30)
Dependencies: IT setup before dev environment; team intro before codebase walkthrough.
