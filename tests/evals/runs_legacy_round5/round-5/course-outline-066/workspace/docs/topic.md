# Course Topic: Introduction to Python Programming
Level: Beginner (no prior experience)
Duration: 8 weeks, 3 hours/week
Target audience: College students and working professionals
Learning outcomes:
- Write and run Python programs
- Use variables, data types, and operators
- Control flow (if/else, loops)
- Define and use functions
- Work with files and basic data structures (lists, dicts)
- Introduction to OOP (classes, objects)
- Basic error handling
Assessment: weekly quizzes (20%), 2 assignments (30%), final project (40%), participation (10%)
