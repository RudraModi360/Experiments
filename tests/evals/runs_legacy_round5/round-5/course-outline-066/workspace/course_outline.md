# Course Outline: Introduction to Python Programming

- **Level:** Beginner (no prior experience)
- **Duration:** 8 Weeks (3 hours / week)
- **Target Audience:** College students and working professionals
- **Overall Course Learning Outcomes:**
  - Write and run Python programs independently.
  - Use variables, data types, and operators effectively.
  - Control program flow using conditional statements and loops.
  - Define and use functions for modular code design.
  - Work with basic data structures (lists, dictionaries, tuples) and external files.
  - Understand and apply fundamental Object-Oriented Programming (OOP) concepts (classes, objects).
  - Handle errors and exceptions gracefully using try/except blocks.

---

## Grade Breakdown & Assessment Structure
- **Weekly Quizzes (20%):** Short knowledge checks at the end of weeks 1–7 to reinforce concepts.
- **Assignments (30%):** 
  - Assignment 1 (Due end of Week 4): Covers fundamentals, control flow, and functions.
  - Assignment 2 (Due end of Week 7): Covers data structures, file I/O, and error handling.
- **Final Project (40%):** Capstone project integrating all course concepts (due end of Week 8).
- **Participation (10%):** Active engagement in discussions, Q&A, and in-class exercises.

---

## Weekly Schedule & Module Breakdown

### Week 1: Getting Started with Python & Basic Syntax
- **Module:** 1. Introduction and Setup
- **Lessons:**
  - 1.1 Setting up the Environment (Installing Python, VS Code / PyCharm, running the REPL).
  - 1.2 Writing Your First Python Program (`print`, comments, basic syntax).
  - 1.3 Variables and Assignment.
- **Weekly Learning Outcomes:** Install Python tools, execute scripts, and store simple values in variables.
- **Assessment:** Quiz 1 (Basic syntax & variables).

### Week 2: Data Types, Operators, and Input
- **Module:** 2. Core Data Types and Expressions
- **Lessons:**
  - 2.1 Numeric Types (`int`, `float`) and Arithmetic Operators.
  - 2.2 Strings and String Methods (concatenation, formatting).
  - 2.3 Boolean Type, Comparison Operators, and User Input (`input()`).
- **Weekly Learning Outcomes:** Manipulate numbers and text, evaluate expressions, and accept user input.
- **Assessment:** Quiz 2 (Data types & operators).

### Week 3: Control Flow (Conditional Statements)
- **Module:** 3. Making Decisions
- **Lessons:**
  - 3.1 Conditional Execution (`if`, `elif`, `else`).
  - 3.2 Logical Operators (`and`, `or`, `not`).
  - 3.3 Nested Conditionals and Practical Decision-Making Examples.
- **Weekly Learning Outcomes:** Write branching logic to control program execution paths.
- **Assessment:** Quiz 3 (Conditionals & logic).

### Week 4: Control Flow (Loops) & Introduction to Functions
- **Module:** 4. Iteration and Modular Code
- **Lessons:**
  - 4.1 `while` loops and infinite loop prevention.
  - 4.2 `for` loops, `range()`, and iteration.
  - 4.3 Defining Functions (`def`, parameters, return values).
- **Weekly Learning Outcomes:** Automate repetitive tasks with loops and write reusable code blocks using functions.
- **Assessment:** 
  - Quiz 4 (Loops & functions).
  - **Assignment 1 Due** (Covers Weeks 1–4: fundamentals, control flow, functions).

### Week 5: Data Structures (Lists and Tuples)
- **Module:** 5. Collections: Sequences
- **Lessons:**
  - 5.1 Introduction to Lists (indexing, slicing, mutable operations).
  - 5.2 Common List Methods (`append`, `pop`, `sort`, etc.).
  - 5.3 Tuples and Packing/Unpacking.
- **Weekly Learning Outcomes:** Store and manipulate collections of ordered data efficiently.
- **Assessment:** Quiz 5 (Lists & tuples).

### Week 6: Data Structures (Dictionaries and Sets) & File I/O
- **Module:** 6. Mappings, Sets, and Files
- **Lessons:**
  - 6.1 Dictionaries (key-value pairs, methods like `.keys()`, `.values()`, `.items()`).
  - 6.2 Sets (unique collections, set operations).
  - 6.3 Reading and Writing Text Files (`open()`, `with` statement).
- **Weekly Learning Outcomes:** Manage key-value data, ensure uniqueness with sets, and read/write persistent data to files.
- **Assessment:** Quiz 6 (Dictionaries, sets, files).

### Week 7: Error Handling & Introduction to Object-Oriented Programming (OOP)
- **Module:** 7. Robustness and Objects
- **Lessons:**
  - 7.1 Error Handling (`try`, `except`, `finally`, raising exceptions).
  - 7.2 Introduction to OOP: Classes and Objects (`__init__`, attributes).
  - 7.3 Methods and Object State.
- **Weekly Learning Outcomes:** Handle runtime errors gracefully and design basic class-based models.
- **Assessment:** 
  - Quiz 7 (Error handling & OOP basics).
  - **Assignment 2 Due** (Covers Weeks 5–7: data structures, file I/O, error handling).

### Week 8: Capstone Project & Course Wrap-Up
- **Module:** 8. Integration and Final Presentation
- **Lessons:**
  - 8.1 Capstone Project Workshop & Code Review.
  - 8.2 Final Q&A, Best Practices, and Next Steps in Python.
  - 8.3 Final Project Presentations / Submission.
- **Weekly Learning Outcomes:** Synthesize all course concepts into a complete, working Python application.
- **Assessment:** **Final Project Due (40% of grade).**
